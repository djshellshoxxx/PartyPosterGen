# User Guide

- Live site: https://djshellshoxxx.github.io/PartyPosterGen/
- Start from a template family (16 nightlife families), fill in whichever event fields you need (all are optional), and add uploaded images, stickers and effects.
- Output sizes, saving editable projects and emailing posters are described in the README sections of the same names.
- **Email Poster** attaches the rendered PNG and offers message templates. It needs the optional mail service to be deployed (see the Developer Guide).
- Background stock images come from Pexels. The README records Pexels' licence terms; procedural backgrounds are the fallback.
