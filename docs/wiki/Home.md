# PartyPosterGen Wiki

PartyPosterGen (Circuit Drift Labs) is a template-first generator for rave, DJ, hip-hop and party posters. It runs in
the browser. An optional Node mail service sends posters by email, because SMTP credentials cannot live in the static site.
